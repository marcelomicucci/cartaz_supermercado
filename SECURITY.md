# Segurança

## Versões suportadas

A versão mais recente publicada na página de releases recebe correções de
segurança.

## Reportando uma vulnerabilidade

Não publique detalhes sensíveis em uma issue aberta. Use o recurso
**Security advisories** do GitHub neste repositório para enviar um relato
privado, incluindo impacto, passos para reprodução e versão afetada.

O projeto não coleta dados e não se comunica com servidores externos durante
o uso normal.
